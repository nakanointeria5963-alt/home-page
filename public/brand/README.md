# ROGUE PINK ブランド素材

名刺・アパレル・SNSなどで使う共通素材。スマホからは
`https://roguepink.com/brand/ファイル名` で直接ダウンロードできる。

## ロゴ

| ファイル | 中身 | 使いどころ |
| --- | --- | --- |
| `logo-transparent.png` | 背景透過・グラデーションのまま | 黒背景でも白背景でも写真の上でも使える |
| `logo-mark.png` | Rモノグラムのみ | アイコン、小さく使うとき |
| `logo-wordmark.png` | 「ROGUE PINK」の文字のみ | 横長のスペース、名刺の裏など |
| `logo-foil-pink.png` | 単色ベタ(#FF2E88) | シルク印刷・刺繍など、色を指定して1色で出す加工 |
| `logo-foil-pink.svg` | 同じもののベクター版 | 拡大しても輪郭がボケない |
| `logo-foil-plate.png` / `.svg` | 単色ベタ(**K100%の黒**) | **箔押しの版データ**。下の注意を参照 |

元データ `../logo.jpg` は背景が濃紺で塗りつぶされている。上記はそれを取り除いたもの。

### 箔押しの版は黒で作る

箔押しの版データは、箔の色(ピンク)ではなく **K100%の黒一色**で描くのが業界の決まり。
「どの形を箔にするか」を示す型紙であって、色の指定ではないため。
ピンクで入稿すると刷り直しになるので `logo-foil-plate` を使う。

また、版は**半透明部分があってはいけない**。ベタか、何もないかのどちらか。
このファイルは中間調が輪郭の0.4%のみで、実質完全なベタになっている。

## QRコード

| ファイル | 中身 |
| --- | --- |
| `qr-roguepink.png` | 2000px・白地に黒。印刷用 |
| `qr-roguepink.svg` | ベクター版 |

リンク先は `https://roguepink.com`。短縮URLは使っていないので、
外部サービスが終了してもQRが死ぬことはない。

読み取りの注意:

- 印刷サイズは **20mm角以上**
- 周囲の白い余白を削らない(データにはすでに余白が入っている)
- **箔押しにしない**。光を反射して読み取れなくなる
