# ROGUE PINK ブランド素材

名刺・アパレル・SNSなどで使う共通素材。スマホからは
`https://roguepink.com/brand/ファイル名` で直接ダウンロードできる。

## ロゴ

| ファイル | 中身 | 使いどころ |
| --- | --- | --- |
| `logo-transparent.png` | 背景透過・元のグラデーションのまま | 黒背景・写真の上など、どこに置いても四角が出ない |
| `logo-mark.png` | Rモノグラムのみ(背景透過) | アイコン、小さく使うとき |
| `logo-wordmark.png` | 「ROGUE PINK」の文字のみ(背景透過) | 横長のスペース、名刺の裏など |
| `logo-foil-pink.png` | 単色ベタ(#FF2E88)・背景透過 | 箔押し・シルク印刷・刺繍など「1色でしか出せない」加工用 |

元データ `../logo.jpg` は背景が濃紺で塗りつぶされているため、
黒地に置くと四角い枠が浮く。上記はそれを取り除いたもの。

## QRコード

| ファイル | 中身 |
| --- | --- |
| `qr-roguepink.png` | 2000px・白地に黒。印刷用 |
| `qr-roguepink.svg` | 同じもののベクター版。拡大しても劣化しない |

リンク先は `https://roguepink.com`。短縮URLは使っていないので、
外部サービスが終了してもQRが死ぬことはない。

読み取りの注意:

- 印刷サイズは **20mm角以上**
- 周囲の白い余白を削らない(データにはすでに余白が入っている)
- 濃い色 on 明るい背景が最も確実。黒地に置くときは白い四角を敷く

## 名刺

肩書きは **Producer** で確定。仕様は `../../docs/business-card.md` を参照。

| ファイル | 中身 |
| --- | --- |
| `card-front-print.png` | 入稿データ・表。97 × 61mm(塗り足し3mm込み)・350dpi |
| `card-back-print.png` | 入稿データ・裏。同上 |
| `card-front.png` / `card-back.png` | 画面で見る用のプレビュー(仕上がりサイズ・角丸つき) |
| `card-title-options.png` | 肩書きを決めたときの比較。記録として残してある |
