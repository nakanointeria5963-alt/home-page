# 名刺仕様 — ROGUE PINK

印刷所やCanvaにそのまま渡せるように、決まったことをまとめたもの。
デザイン案の画像は `public/brand/card-mockup.png`。

## 考え方

事業が複数あるので、名刺に事業内容は書かない。事業が増えるたび刷り直しになるうえ、
情報が多いと読まれない。**名刺はサイトへの入り口**と割り切り、
詳しいことは `roguepink.com` 側で更新していく。

## サイズ・体裁

| 項目 | 値 |
| --- | --- |
| 仕上がりサイズ | 91 × 55 mm(日本の標準) |
| 塗り足し | 上下左右 3mm(全面黒なので必須) |
| 文字の安全マージン | フチから 5mm 以上内側 |
| 解像度 | 350dpi 以上 |
| カラーモード | CMYK |
| 角 | 角丸 1.5mm(任意。安価に印象が変わる) |

## 表面

- 背景:`#0D0F16` 全面
- 中央に `public/brand/logo-transparent.png` を **幅36mm** で配置
- それ以外は何も置かない

## 裏面

背景は表と同じ `#0D0F16`。内側 7mm を余白として、左にテキスト・右にQR。

左カラム(上から):

| 要素 | 内容 | 指定 |
| --- | --- | --- |
| ワードマーク | `logo-wordmark.png` | 幅 25mm |
| 名前 | `NOBU` | 約 7mm・太字・字間 0.14em・白 |
| 罫 | ピンクの短い線 | 11 × 0.45mm・`#FF2E88` |
| 本名 | `中野 信宏` | 約 2.5mm・字間 0.22em・`#A7A6B8` |
| 一行 | `ありがとうと言ってもらいたい。` / `そして、言いたい。` | 約 2.3mm・行間 1.75・`#FF8FC4` |
| URL | `roguepink.com` | 約 3mm・太字・白 |
| メール | `info@roguepink.com` | 約 2.4mm・`#A7A6B8` |

右:

- 白の角丸プレート 21 × 21mm(角丸 1.2mm)、上下中央
- その中に `qr-roguepink.png` を 17mm 角で配置(白い余白が四方に2mm残る)

## 書体

モックアップは環境にあった代替書体で組んである。実物はロゴに合わせて
**幾何学的なサンセリフ**(Montserrat / Poppins / Futura系)を使う。
和文は Noto Sans JP。

## 印刷・加工

「かっこよさ」はデザインより紙と加工で決まる。

- 用紙:220kg 以上。薄いと安っぽく見える
- おすすめ:**マット黒 + ロゴをピンクの箔押し**(箔用データは `logo-foil-pink.png`)
- 代替:活版印刷(文字が凹む)、エンボス
- 注意:マット黒は指紋が目立つ。気になるならマットPP加工を足す
- 全面黒はムラが出やすい。黒ベタに実績のある印刷所を選ぶ
