# 映画のリポジトリとの関係(作業用の説明書)

> **この文書は配管の説明だけ。**作品の中身は一切書かない —— ここは公開リポジトリだから。

## 2つのリポジトリ

| | 中身 | 公開 |
|---|---|---|
| **`roguepink/home-page`**(ここ) | ROGUE PINK のサイト。**完成した文章だけ** | **public** |
| **`roguepink/ai-film-project`** | 映画の作業場。脚本・キャラ設定・素材・帳簿・口述メモ | **private** |

**本番の住所は https://roguepink.com。**
`home-page-pnpg.vercel.app` も生きているが予備。**資料に載せるのは `roguepink.com` のほう。**

## ★ 大原則 —— 部屋と棚は別

**セッション(作業する部屋)とリポジトリ(物をしまう棚)は別物。**

- **部屋はどちらでもよい。**ここのセッションで映画の作業をしてよい(2026-08-23 ノブさん指示)
- **棚は必ず `ai-film-project`。**

### ここに置いてはいけないもの(例外なし)

**キャラクターの参照画像 / 生成した画像・動画 / 脚本 / キャラ設定 / 帳簿 /
本人の口述メモ / 未公開の企画 / クレジットの残高。**

**Git は履歴が残る。**一度 push したら、あとで消しても掘り出せる。
**「あとで消せばいい」は成立しない。**迷ったら置かない。

### ここに置いてよいもの

**本人が公開すると決めた、完成した文章だけ。**
出す先は `src/app/journal`(制作日誌)・`src/app/writing`(執筆)・`src/app/music`(音楽)。

## 映画の棚を開ける手順

1. `add_repo`(owner: `roguepink`, repo: `ai-film-project`, access: `"push"`)
2. 返ってきた clone コマンドを実行
3. `register_repo_root` を呼ぶ(向こうの `CLAUDE.md` が読み込まれる)

**向こうの `CLAUDE.md` に運用のルールが全部書いてある。開いたら必ず読む。**
とくに「home-page 側のセッションから映画の作業をするとき」の節。

## ⚠ 並行するときに取り合いになるファイル

映画側のセッションと同時に動かすときだけの話。

| ファイル(映画側) | 書いてよいのは |
|---|---|
| `assets/ledger.md` / `shots/shot-list.md` | **映画側の部屋だけ。**ここからは書かない |
| `characters/*.md` / `docs/*-prompts.md` | **詰めをしている部屋だけ** |

ここから台帳に載せたい行が出たら、**その場では書かず、区切りで1回にまとめて入れる。**
